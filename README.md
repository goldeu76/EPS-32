# EPS-32

🌡️ 스마트 온습도 및 얼굴 인식 상태 알림 시스템이 프로젝트는 허스키렌즈(HuskyLens)의 얼굴 인식 기능과 온습도 센서를 결합하여, 현재 온도와 사용자의 존재 유무에 따라 OLED 화면과 네오픽셀 LED로 상태를 알려주는 MicroPython 기반 시스템입니다.  🛠️ 사용된 센서 및 하드웨어코드에 포함된 하드웨어 및 센서 구성은 다음과 같습니다:  마이크로컨트롤러 (MCU): ESP32 (I2C 통신을 위해 21번, 22번 핀 사용)  AI 비전 센서: HuskyLens (I2C 연결, 얼굴 인식 알고리즘 사용)  디스플레이 모듈: 0.96인치 OLED (SSD1306 칩셋, 128x64 해상도, I2C 연결)  LED 모듈: 네오픽셀 (NeoPixel, 12구)  온습도 센서: DHT11  터치 센서: 디지털 터치 센서 1개 사용 (추가로 3개의 핀이 할당되어 있으나 현재는 예비용)  🔌 핀 맵 (Pin Mapping)센서와 MCU 간의 연결 정보입니다:  I2C 통신 (HuskyLens & OLED 공통)SDA: Pin 21  SCL: Pin 22  네오픽셀 (NeoPixel): Pin 14  DHT11 온습도 센서: Pin 27  터치 센서Touch 1 (메인 초기화/해제용): Pin 33  Touch 2 ~ 4 (미사용 예비 핀): Pin 32, 35, 34  📋 주요 동작 및 시나리오이 시스템은 주기적으로 DHT11 센서로 온도를 측정하고, 허스키렌즈로 ID가 1 또는 2로 등록된 얼굴을 감지합니다.  터치 강제 해제 (최우선 동작): 1번 터치 센서를 누르면 온도나 얼굴 인식 여부와 관계없이 OLED에 Status: CLEARED!가 출력되며, 네오픽셀이 초록색으로 켜집니다.  정상 상태 (10℃ 초과 ~ 28℃ 미만): Status: Normal이 출력되며, 네오픽셀이 은은한 흰색으로 켜집니다.  저온 경고 (10℃ 이하 + 얼굴 감지됨): 지정된 사람의 얼굴이 인식되고 온도가 10도 이하일 때 Status: COLD DANGER!가 출력되며 네오픽셀이 붉은색으로 켜집니다.  고온 주의 (28℃ 이상 ~ 33℃ 미만 + 얼굴 감지됨): Status: HEAT WARING!이 출력되며, 네오픽셀이 주황/노란색으로 점등됩니다.  고온 위험 (33℃ 이상 + 얼굴 감지됨): Status: HEAT DANGER!가 출력되며, 네오픽셀이 강렬한 붉은색으로 점등됩니다.  대기 상태 (Standby): 위 조건에 해당하지 않거나, 이상 온도 범위임에도 얼굴이 감지되지 않으면 Status: Standby가 출력되고 네오픽셀이 어두운 흰색으로 대기 상태를 표시합니다.  ⚙️ 필수 라이브러리 (Prerequisites)MicroPython 환경에서 다음 라이브러리가 필요합니다:  neopixel, machine, dht, time (MicroPython 내장 라이브러리)  pyhuskylens.py (HuskyLens 통신용 드라이버)  ssd1306.py (OLED 디스플레이 제어용 드라이버)
